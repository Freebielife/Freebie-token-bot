# Freebie-token-bot

Тестовый бот-каталог TON для Cloudflare Workers Free. /start → KITO → HTML-виджет. Все цены, объёмы и график демонстрационные. Настоящие данные ещё не подключены.

## Подключение существующего Worker

1. Cloudflare → Workers & Pages → freebie-token-bot → Settings → Builds → Connect.
2. Выберите этот репозиторий, ветку main, корневой каталог /.
3. Build command: npm test
4. Deploy command: npx wrangler@4 deploy
5. Сохраните существующие runtime Secrets BOT_TOKEN и SETUP_KEY. Не добавляйте их в GitHub или build variables.
6. Проверьте PUBLIC_BASE_URL в wrangler.toml: он должен совпадать с production workers.dev URL вашего Worker. Не используйте адрес preview.
7. После публикации откройте production адрес /health. Должно быть github-v1.
8. Откройте /setup и введите существующий SETUP_KEY (не токен бота). Нажмите подключение; оно повторно установит webhook с новым производным секретом. Без этого переход со старой версии не завершён.
9. В Telegram отправьте /start, нажмите KITO, затем «Проверить обновление». Должно измениться время внутри той же карточки. Проверьте телефон и Desktop.

## Проверки

Node.js 22+: npm test. Нет runtime npm-зависимостей; Wrangler 4 используется только при публикации.

Локальные тесты подменяют Telegram API: они не подтверждают доступность sendWidget для конкретного аккаунта/клиента. Реальная проверка проводится после deployment. Browser preview также не воспроизводит движок Telegram.

## Безопасность и ограничения

Секреты не выводятся в ответы или логи. /setup требует SETUP_KEY; webhook использует производный SHA-256 секрет. Адрес webhook берётся только из PUBLIC_BASE_URL, а не из переданного клиентом Host. Проверка Origin удалена: доступ защищён секретом, ошибки теперь различимы. Не отправляйте секреты в переписку. Используйте случайный SETUP_KEY не короче 32 символов.

Защита от повторной доставки работает только внутри текущего isolate; при перезапусках дубликаты возможны. Для массового запуска потребуются постоянное хранение, ограничение частоты и измерение лимитов источника данных. Нет базы, расписания, платных рассылок, кошельков и транзакций. Кнопка обновления меняет только демонстрационный статус.

Официальные документы: https://core.telegram.org/bots/widgets и https://developers.cloudflare.com/workers/ci-cd/builds/ .
